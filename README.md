# Автоматические подписки FOMO

Программа открывает профили из списка и подписывается на них с вашего аккаунта [fomo.family](https://fomo.family). Она запоминает результат для каждого `userId`, поэтому после остановки продолжает с оставшихся профилей. Профили без истории торговли тоже входят в список.

Парсер остаётся у владельца проекта и в этот репозиторий не входит. Для подписок **не нужны Docker и ключи FOMO API**: готовый список находится в `data/all_profiles.csv`. Владелец обновляет его вместе с базой `data/traders.sqlite3` через Git.

## Что понадобится

- Компьютер с Windows 10/11 или актуальной macOS и доступом к интернету.
- [Google Chrome](https://www.google.com/chrome/) — программа использует отдельный профиль установленного Chrome.
- [Python](https://www.python.org/downloads/) версии 3.10 или новее.
- [Git](https://git-scm.com/downloads) и [Git LFS](https://git-lfs.com/) — для получения и обновления базы из репозитория.
- Доступ к этому репозиторию и аккаунт FOMO, в который можно войти через Google.

Если что-то из этого уже установлено, повторно устанавливать не нужно. Команды ниже вводятся в **PowerShell** на Windows или в **Терминале** на Mac. После каждой команды нажимайте Enter. Строки, начинающиеся с `#`, — пояснения, их вводить не нужно.

## Установка на Windows

1. Установите Chrome, Python и Git по ссылкам выше. В установщике Python отметьте **Add python.exe to PATH**, если такой пункт показан. Git LFS обычно доступен вместе с Git; если команда `git lfs version` ниже не работает, установите Git LFS отдельно с сайта по ссылке выше.
2. Откройте меню «Пуск», найдите **PowerShell** и откройте его. Проверьте установки:

   ```powershell
   py -3 --version
   git --version
   git lfs version
   ```

   Если `py` не найден, попробуйте `python --version` и далее заменяйте `py -3` на `python`. Если версия Python ниже 3.10, обновите Python. После установки программ иногда нужно закрыть и снова открыть PowerShell.
3. Скачайте проект в папку «Документы». В команду `git clone` подставьте ссылку на репозиторий, которую вам дал владелец проекта:

   ```powershell
   cd $HOME\Documents
   git lfs install
   git clone https://github.com/md-invt05/Fomo_subs.git
   cd Fomo_subs
   git lfs pull
   ```

   Если репозиторий приватный, Git может попросить войти в GitHub. Входите в аккаунт, которому выдан доступ. После скачивания должны появиться `data/all_profiles.csv` и `data/traders.sqlite3`.
4. Создайте отдельное окружение Python и установите библиотеку для управления браузером:

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements-follow.txt
   ```

   Активация окружения не нужна: в командах ниже указан путь к нужному Python.
5. Создайте файл настроек и откройте его в Блокноте:

   ```powershell
   Copy-Item env.example .env
   notepad .env
   ```

   В строке `FOLLOW_ACCOUNT=` укажите **свой ник на FOMO** без `@`. Сохраните файл (`Ctrl+S`) и закройте Блокнот. Остальные значения для первого запуска оставьте как в примере.

## Установка на macOS

1. Установите Chrome и Python по ссылкам выше. Откройте приложение **Терминал** (через Spotlight: `⌘` + пробел, затем «Терминал»). Проверьте Python:

   ```bash
   python3 --version
   ```

   Если версия ниже 3.10, установите новую с сайта Python. Для Git выполните `git --version`; если macOS предложит установить инструменты командной строки, согласитесь и дождитесь окончания установки. Git LFS установите с [git-lfs.com](https://git-lfs.com/) или, если уже пользуетесь Homebrew, командой `brew install git-lfs`.
2. Скачайте проект в «Документы»:

   ```bash
   cd ~/Documents
   git lfs install
   git clone https://github.com/md-invt05/Fomo_subs.git
   cd Fomo_subs
   git lfs pull
   ```

   Если репозиторий приватный, войдите в GitHub под аккаунтом с доступом. Проверьте, что в папке `data` появились оба файла: `all_profiles.csv` и `traders.sqlite3`.
3. Установите библиотеку браузера в отдельное окружение:

   ```bash
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements-follow.txt
   ```

4. Создайте настройки и откройте их в TextEdit:

   ```bash
   cp env.example .env
   open -e .env
   ```

   Поменяйте `FOLLOW_ACCOUNT=ArmedSlimPony` на **свой ник FOMO** без `@`, сохраните файл (`⌘S`) и закройте TextEdit.

## Первый вход через Google

Сначала убедитесь, что у вас нет открытых окон Chrome, созданных этой программой. Обычный Chrome закрывать не обязательно: для программы создаётся **отдельный браузерный профиль** в `follow_data/chrome_profile`.

Windows (PowerShell, находясь в папке `Fomo_subs`):

```powershell
.\.venv\Scripts\python.exe fomo_follow.py login
```

macOS (Терминал, находясь в папке `Fomo_subs`):

```bash
.venv/bin/python fomo_follow.py login
```

Откроется окно Chrome. Войдите на FOMO через Google **в тот же аккаунт, чей ник указан в `.env`**. Дождитесь загрузки своего профиля. Закройте **все окна этого отдельного профиля** и вернитесь в PowerShell/Терминал. Нажмите Enter. Появится сообщение о сохранении сессии. Пароль, куки и токены не нужно никому передавать.

Если окно не появилось или Chrome установлен в необычной папке, укажите полный путь к исполняемому файлу в `.env` через `CHROME_PATH=`. Примеры путей приведены в `env.example`.

## Пробный запуск и постоянная работа

Для проверки обработайте сначала **три профиля**. Программа сверит аккаунт, затем откроет профили и подтвердит состояние кнопки `Following` после обновления страницы.

Windows:

```powershell
.\.venv\Scripts\python.exe fomo_follow.py run --max-profiles 3
.\.venv\Scripts\python.exe fomo_follow.py status
```

macOS:

```bash
.venv/bin/python fomo_follow.py run --max-profiles 3
.venv/bin/python fomo_follow.py status
```

Для непрерывной обработки запускайте `run` **без** `--max-profiles`:

```text
Windows: .\.venv\Scripts\python.exe fomo_follow.py run
macOS:   .venv/bin/python fomo_follow.py run
```

Окно терминала и окно Chrome оставьте открытыми. Если все текущие профили обработаны, программа ждёт новые записи в CSV и проверяет файл примерно раз в минуту. Закрытие терминала прервёт работу; после нового запуска прогресс сохранится. Одновременно запускайте только **один** экземпляр `run`.

Чтобы остановить программу, нажмите `Ctrl+C` в терминале с `run`. Также можно открыть **второй** PowerShell/Терминал в той же папке и выполнить команду `fomo_follow.py stop` с тем же путём к Python, что выше. Дождитесь завершения текущих действий браузера. После остановки команда `status` покажет счётчики.

### Что означают счётчики `status`

| Статус | Значение |
| --- | --- |
| `pending` | Профиль ещё не проверялся. |
| `followed` | Подписка подтверждена в браузере. |
| `already_following` | Подписка существовала раньше. |
| `retry` | Проверка временно не удалась; программа повторит её позже. |
| `unavailable` | Профиль недоступен по текущему нику. |
| `ambiguous_handle` | Один ник соответствует нескольким `userId`; нужна ручная проверка. |
| `skipped_self` | Собственный профиль, на него подписываться не нужно. |
| `running` | Профиль сейчас обрабатывается. |

## Настройки

Все настройки подписок находятся в `.env`. После изменения файла остановите `run` и запустите его снова.

| Настройка | Что делает | Начальное значение |
| --- | --- | --- |
| `FOLLOW_ACCOUNT` | Ваш ник FOMO без `@`; перед подписками программа проверяет аккаунт. | `ArmedSlimPony` — **замените на свой** |
| `FOLLOW_WORKERS` | Число одновременно открытых вкладок. | `2` |
| `FOLLOW_RPM` | Общий предел обрабатываемых профилей за минуту, независимо от числа вкладок. | `10` |
| `FOLLOW_MAX_PROFILES` | Сколько профилей обработать за запуск; пустое значение означает непрерывную работу. | Пусто |
| `FOLLOW_HEADLESS` | Запуск Chrome без видимого окна. | `0` |
| `FOLLOW_SOURCE` | CSV со списком всех профилей. | `data/all_profiles.csv` |
| `FOLLOW_DB` | Локальная база прогресса подписок. | `follow_data/follow_state.sqlite3` |
| `FOLLOW_PROFILE_DIR` | Отдельный профиль Chrome с сохранённым входом. | `follow_data/chrome_profile` |
| `CHROME_PATH` | Необязательный путь к Chrome, если он не найден автоматически. | Не задан |

`FOLLOW_HEADLESS=1` пока не рекомендуется: при проверке FOMO не загрузил сохранённый аккаунт в скрытом Chrome. Оставьте `0`. Не ставьте сразу большое число вкладок или попыток в минуту; сначала проверьте несколько профилей и наблюдайте за результатом. При CAPTCHA, выходе из аккаунта или неожиданном интерфейсе программа останавливается и сообщает причину. После повторного входа через `login` запустите `run` ещё раз.

## Как получать обновления списка

Владелец проекта обновляет базу и CSV в Git. Чтобы получить новый список на компьютере с подписками:

1. Остановите `run` и дождитесь закрытия его Chrome.
2. В папке проекта выполните `git pull` и `git lfs pull`.
3. Если в обновлении изменился `requirements-follow.txt`, повторите команду установки библиотеки из инструкции для своей системы.
4. Запустите `run` снова. Повторный вход через Google обычно не нужен; уже завершённые подписки остаются в `follow_data`.

Не удаляйте папку `follow_data`: в ней находятся сохранённая сессия Chrome и история подписок. Не отправляйте её другим людям и не добавляйте в Git.


## Файлы проекта

```text
fomo_follow.py          Команды login, run, status, stop
fomo_subs/config.py     Чтение настроек
fomo_subs/storage.py    Очередь и результаты подписок
fomo_subs/browser.py    Chrome, проверка аккаунта и кнопки Follow
fomo_subs/service.py    Параллельная обработка и ограничение скорости
fomo_subs/cli.py        Командная строка
data/all_profiles.csv   Список профилей для подписок; обновляется через Git
data/traders.sqlite3    База парсера; обновляется через Git LFS
follow_data/             Локальная сессия и прогресс; в Git не отправляется
```

Проверка кода подписчика разработчиком: `python -m unittest -v test_fomo_follow.py`.
